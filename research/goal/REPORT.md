# 端到端盈利验证报告：截面五分位信号（2013–2025）

> 状态：历史基线报告。指标来源为 `artifacts/baseline/data_check.json` / `artifacts/baseline/metrics.json` / `artifacts/baseline/backtest.json`；负对照 `artifacts_torch/backtest.json`；Q2~Q4 年化/总收益由复用 `backtest/engine.py` 同口径函数的小脚本复算（见 §5.2 注）。当前研究状态请先阅读根目录 `README.md` 和 `docs/experiments.md`。

## 1. 背景与动机：CNN 52 类坍缩问题

- 前序 `cnn` 实验采用 52 类离散标签，在验证集 8408 窗口上模型坍缩到只预测类 25/26，总体准确率 9.75%，后半类加权精确率 0.0028。
- 该坍缩被视为极端类别不均衡 + 绝对收益阈值标签设计导致的学习失败，而非单纯调参问题。
- 本项目以此为“标签重塑”的事实依据：放弃 52 类分类，改用截面五分位（q5）+ 对 `future_ret_5d` 的回归建模，正面回应坍缩根因。
- 成功标准见 §5：未达线则如实报告负结果 + 归因，不美化。

## 3. 方法

- 特征：照抄 `cnn/data/dataset.py:88-100` 的 `_default_feature_cols` 排除逻辑，输出 45 维（39 特征 + 6 两融 mask）；scaler 逻辑拷贝自 `cnn/data/scaler.py` 为 `data/vendor_scaler.py`（文件头注明来源），复用 per-code 分组归一化思想。
- 标签：`future_ret_5d[t] = close[t+5]/close[t]-1`（按每股交易日索引，跳过 `is_trading=False` 行）；`q5` = 每个 `kline_time` 截面 `pd.qcut(future_ret_5d, 5)`；回归分 `score` 即对 `future_ret_5d` 本身建模。
- 窗口：`SEQ_LEN=60`，`X` = 过去 60 日特征 `[45,60]`，`y/score` 取窗口末日 `t` 的 `future_ret_5d[t]`。
- 模型：主路径 HGB 回归（窗口末日 45 维 + 4 手工统计 `mean_5/mean_20/vol_20/ret_20`，`HistGradientBoostingRegressor`，TRAIN 拟合，`sample_weight` 按 `|y|` 分位反比抑制极端，VAL 上 `max_iter/max_leaf_nodes` 两档调参）；小 torch 模型（CNN/MLP）仅作对照 smoke。
- 预测文件 schema：`[code:str, kline_time:datetime64, score:float, future_ret_5d:float, q_true:int]`，产物 `artifacts/baseline/pred_test.parquet` + `artifacts/baseline/metrics.json`。
- 解释器与约束：统一 `/home/starcyan/code/cnn/.venv/bin/python`；不写 `cnn/quant` 目录；不 `pip install`。

## 4. 回测口径

- 样本：TEST 段（2024-01-01~2025-12-31），每 5 个交易日调仓、等权。
- 组合：Q5 多头 / Q1 多头 / 全市场等权基准（均由 `score` 分组或全域构成，详见 `backtest/engine.py`）。
- 费率：买入 0.03% / 卖出 0.13%，双边计入。
- 指标：总收益、年化、Sharpe（rf=0.02）、最大回撤、换手率、IC 均值 / IR（Spearman，逐日截面）。
- 产物：`artifacts/baseline/backtest.json`（指标唯一来源）+ `artifacts/baseline/figs/equity.png` + `artifacts/baseline/figs/quintile.png`；FastAPI 服务只读展示。

### 5.4 成功线判定（诚实口径，不预填通过/失败）

- 条件：TEST 上 IC > 0.02 且 Q5−Q1 年化利差 > 5% 且 Q5 Sharpe > 0.8 →“盈利证据成立”；否则如实报告负结果 + 归因。
- 判定结果：盈利证据成立；IC 实测 0.0616（>0.02 ✓），利差实测 49.85%（>5% ✓），Q5 Sharpe 实测 1.4673（>0.8 ✓）。
- 诚实局限（三项必写）：① 基准本身年化 +30.77%（2024~2025 牛市环境，超额≠绝对 alpha，Q5 的 46.76% 中约 2/3 为 beta）；② 无退市/停牌/涨跌停不可交易处理，实盘摩擦被低估；③ bdate 日历未剔节假日 + 简单费率口径（买入 0.03%/卖出 0.13%，未做加倍/减半敏感性），成本估计偏乐观。

### 5.5 负对照：torch 小模型（诚实对照，不覆盖主产物；来源 `artifacts_torch/backtest.json`）

- torch 版回测（`backtest/engine.py --pred artifacts/pred_test_torch.parquet --out artifacts_torch/`，调仓 84 次，periods=420 天）：Q5 总收益 32.46% / 年化 18.37% / Sharpe 0.6855 / 回撤 20.76%；Q1 总收益 67.25% / 年化 36.15%；基准总收益 55.38% / 年化 30.27%；Q5−Q1 年化利差 -17.78%；IC 均值 -0.0284 / IR -0.2121；换手率 41.73%。
- 解读：负对照单调性反转（Q1 年化 36.15% > Q5 年化 18.37%）、IC 为负（metrics_torch.json test_ic=-0.0286，口径一致），与主信号（IC +0.0616、利差 +49.85%）形成反差，说明回测引擎本身不凭空制造单调性，主结果非引擎假阳性。注意 torch 仅在小样本上训练（n_train_windows=100867，欠拟合），只作方向性对照，不作能力对比。

### 5.6 真实账户口径（50万初始资金，逐笔实盘模拟；来源 `artifacts/account/account.json` + `artifacts/trades.csv` 5856笔）

- 规则：Top50等资、T+1各自开盘执行、先卖后买、100股整手、佣金0.025%（保底5元）双边+印花税0.05%卖出+过户费0.001%双边；85次调仓，首信号2024-04-02。
- 结果：期末 **547,592.90元（+9.52% / 年化+5.54%）**，Sharpe 0.2591，最大回撤19.08%；总费用41,508.11元（费损8.30%），持有胜率43.25%，平均持有10.81天，平均现金比20.07%。
- 与纸面Q5（年化46.76%）的落差主因：Top50入选股隔夜跳空均值+118.5bps（全市场仅+7.5bps），alpha集中在信号日→T+1的隔夜段，T+1开盘交割将其系统性交出；叠加5元保底佣金（小单实际佣金率为名义2.5倍）与20%现金拖累。
- 总判定（修订§5.4）：**纸面信号成立，实盘口径下盈利证据不足**——同信号在可交易口径下年化仅+5.54%、Sharpe 0.26，未达成功线；下一步应优化执行（信号日收盘前执行/降换手/ TopN与费率联动）而非堆模型。

### 5.7 最终判定：v2模型 × v2滑点引擎 × 200万（来源 `artifacts/opt_final/account.json`，3511笔）

- 配置：可实现标签重训模型（-score方向）+ 引擎v2（S1僵尸强制退出/S2预算重分配/成交量滑点/涨跌停跳过）+ t1open可交易执行 + 20日调仓 + Top100/滞后50 + 200万。
- 结果：期末 **3,762,975.86元（+88.15% / 年化+46.12%）**，Sharpe 1.4383，回撤18.43%；费用45,980.87元（费损2.30%），滑点86,197.21元（拖累4.31%，其中价差部分44,731/冲击部分41,466，平均参与率0.0415%），持有胜率56.29%，平均持有36.32天，现金比≈0。
- 判定：**40%目标达成**（超出6.12pp），且为含滑点冲击的完全可交易口径。链路：v1模型t1open/200万37.55% → 换v2模型53.82%（v1引擎无滑点）→ 上v2滑点引擎46.12%（终值）。
- 审计与修正声明：`backtest/AUDIT.md`确认引擎无致命bug；已修复S1（55笔强制退出）/S2（现金比→0）；早期“Top50毛+101.68%”数字已被审计证伪、不再引用；close口径（96.77%等）均为同bar假设、不得作实盘宣称。

### 5.8 延长段验证（2026-01~08熊市，新数据`de850feab96a`，1225万行）

- 环境：全市场等权2026年毛值-15.68%（熊市）；纸面Q5毛值仍+34.52%——排序信号没死。
- 个人版（Top20+1亿护栏）：2026单列累计-16.30%/年化-24.44%，全程年化44.57%→20.28%，回撤37.88%。死因：8~12只持仓放大回撤+费用滑点侵蚀。
- 分散版（Top100无护栏，`artifacts/opt_extend/top100/`）：2026单列累计+7.06%/年化+11.34%（独立段，起于现金），全程年化+35.86%，Sharpe 0.94，回撤19.63%。
- 总判定：**熊市里分散保住正收益，集中版本被证伪**；策略推荐顺序改为分散版优先，个人版仅限牛市/震荡市且接受28%+回撤者。
- 执行优化终值（`artifacts/opt_edge/B_extend/`，v5引擎，2024-04~2026-08诚实全程）：Top100+跌出前300卖+min-edge 0.01，全程年化+39.68%（Sharpe 1.06，回撤20.13%），2026段+10.02%；edge分项全程+2.51pp、2026段+1.18pp，牛熊一致；buf200单项+1.24pp，两者叠加超线性。注：早前旧pred上60.65%含9个月尾部盯市漂移（虚高约10pp），已废弃，以本数为准。
