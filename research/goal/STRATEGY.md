# 实际交易策略（可执行口径，TEST 2024~2025 验证）

> 状态：研究验证策略（有完整回测证据），不是实盘交易系统（无实盘行情/下单模块）。
> 证据链：`artifacts/opt_final/account.json` + `trades.csv`（3511笔）+ `backtest/AUDIT.md`。

## 1. 一句话
每天收盘后算分，次日开盘买入未来5日开盘收益预测最高的一篮子股票，持有约36天后轮换；
分两个版本——**个人版**（Top20+流动性护栏，平均持仓~8只，200万年化 **+44.57%**）与
**分散版**（Top100，平均持仓~105只，年化+46.12%）。证据链：`artifacts/opt_liquid/min100M_p05/`
+ `artifacts/opt_final/account.json` + `backtest/AUDIT.md`。

## 2. 信号模型（v2，`models/train_realizable.py`）
- 模型：HistGradientBoostingRegressor（max_iter=150，63叶），49维特征。
- 特征：45维 per-code 分组归一化因子（39特征+6两融mask，scaler只在2013~2021拟合）+ 4手工统计（mean_5/mean_20/vol_20/ret_20）。
- 标签：**可实现收益** `open[t+6]/open[t+1]-1`（T+1开盘买、5交易日后开盘卖，真能吃到的段）；
  存盘 score 取负后使用（`-score` vs 可吃收益 TEST IC **+0.0764**）。
- 时段：TRAIN 2013~2021 / VAL 2022~2023 / TEST 2024~2025，无跨段泄露。

## 3. 交易规则（`backtest/account_engine_v3.py`；v2见分散版备注）
- 调仓：每20个信号日一次。
- 选股：按 `-score` 取前 **Top20**；持仓股排名跌出前40才卖（滞后带20）。
- 流动性护栏：执行日成交额 < 1亿的候选直接剔除（误杀真实存在，曾砍掉一只+69%的牛股，净结果仍为正）。
- 执行：**各自次日开盘价**（T+1 open）；停牌顺延、涨停跳过不买、无行情强制退出。
- 仓位：等资金权重，100股整手，剩余现金迭代重分配；护栏剔除后平均持仓约8只、现金约12%。
- 风险控制（诚实）：无止损无对冲；个人版回撤28.4%、Sharpe 0.97——集中是把双刃剑。
- 分散版备注：Top100/滞后50/v2引擎，年化+46.12%，回撤18.43%，Sharpe 1.44，适合资金量更大或能接受程序下单者。

## 4. 成本模型（逐笔 reality check）
- 佣金0.025%双边（单笔保底5元）+ 印花税0.05%卖出 + 过户费0.001%双边。
- 滑点（按成交量）：`slip = min(0.03×√参与率 + 0.0005, 0.03)`，买加卖减；
  实测滑点拖累4.31%（价差4.47万/冲击4.15万，平均参与率0.0415%），费用拖累2.30%。

## 5. 业绩（200万，TEST样本外；2026-08延长验证后修订）
- 个人版（Top20+1亿护栏）：2024~2025年化+44.57%，但2026熊市单列-24.44%，全程稀释到+20.28%，回撤37.88%——**已被延长段证伪，降级为备选**。
- 分散版（Top100）：2024~2025年化+46.12%，2026熊市单列+7.06%（市场-15.68%），全程+35.86%，回撤19.63%——**现为推荐主版本**。

## 6. 被证伪的想法：每日触发式调仓（`artifacts/opt_trigger/`）
- 设想"每天看、崩了才动"的便宜保险；实测触发率96%+（日排名噪声天天把持仓股推出阈值），笔数×10~12、费用×14~19，持有期被打到4~5天。
- 年化虽升（R200达+94%），但回撤不降反升、每日都要操作——个人不可操作，不采纳。要保险需更松阈值+持有期迟滞，另立实验。
- 2026-09-05补测Top100三倍规则（Top100买/跌出300卖/每日检查+min-edge 0.01，v5引擎亲跑`opt_trigger_top100/`）：
  TEST年化45.58%（−6.4pp于calendar挑战版，24114笔、持有5.16天、费损17.87%+滑点34.13%，420天全触发），
  2026熊市年化−11.19%（11118笔，持有4天）——三倍规则同样判负，冠军仍是calendar挑战版。
  机制：100只持仓下每天必有股票掉出前300，缓冲带形同虚设，平均持有≈信号期限本身（5天），纯属为噪音交税。

## 7. 上实盘还缺什么（按优先级）
1. 实盘行情+下单模块（当前只有回测执行，无live交易链路）。
2. 退市/ ST /长期停牌的事前过滤（回测只做事后跳过）。
3. 节假日历（回测用周一~周五近似）。
4. 滑点系数敏感性 + 按年拆解（2024 vs 2025稳定性待验）。
5. 信号时效：模型需在每个交易日收盘后、次日开盘前跑完全市场算分（约200万行窗口，CPU约10分钟级，需工程化）。
