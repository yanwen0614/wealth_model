# 换手 + 行业暴露归因（exit / 强买门槛）

- 任务：`20260916_0010_turnover-industry-attribution`（analyze 模式，不改源码）
- 区间：2026-01-05 ~ 2026-08-31，160 交易日；基准沪深300（000300.SH）
- 样本：`logs/backtest_idx_e0e5_rolling`（rolling topn5/10/20）、`backtest_idx_target_{b500,exitnp}_s{5,10,20,50}`、`backtest_sbg_{b500,exitnp}_s{5,10,50}_t{0.00,0.02,0.03,0.05}`，共 33 个目录 × 6 臂（E0–E5）
- 数据源：
  - 成交明细 `logs/backtest_*/holdings_*.csv`（`entry_date/exit_date/code/weight/open_t1/open_t6/ret_gross/ret_net`）
  - 行业成分（申万一级，31 个）`Z:/test/industry_weight/8010*0.SI.parquet`（`行业指数代码/成分股代码/交易日期`，point-in-time）
  - 基准成分权重 `Z:/test/index_weight/000300.SH.parquet`
- 产物 CSV：`logs/attribution_20260916/`（`turnover`、`industry_active_long`、`industry_summary`、`industry_pnl`、`config_master`）
- 口径与近似：
  - 换手 = 252 × mean(日单边成交额/NAV)，`weight` 为建仓时 NAV 占比；**年化单边换手以 ×NAV 倍数表示**（如 16.5 = 1650%/年）
  - 成本拖累估算 = 2 × 年化单边换手 × 0.075%（买佣 0.025% + 卖佣 0.025% + 印花税 0.025%）
  - 行业暴露 = 逐日「在持股票建仓权重」按申万一级汇总后对全期取均值（未持有日计 0）
  - 行业 P&L = Σ(weight × ret_net)，为**简单求和近似**（与复利 NAV 有偏差，仅用于横向比较）
  - 行业映射按建仓日取 point-in-time（自建二分查找，非 merge_asof）

1. **出口规则是换手的第一驱动变量**：`exitnp` 换手仅为 `b500` 的 **1/2.7**，持仓期 21.6 天 vs 7.9 天。缓冲 500 看似"宽松"，但低 IC 模型排名极不稳定（b500_s5 共 159 笔、146 个不同 code、中位持仓 7 天），实际高频换手。

3. **成本拖累（估算）**：b500 ≈ 7.3%/年、rolling ≈ 7.0%/年、exitnp ≈ 2.7%/年、sbg b500 t5% ≈ 3.8%/年。成本差约 4.6pp，**不足以解释 b500 与 exitnp 之间 17pp 的超额差**，其余来自持仓/择时路径差异。

**要点**

1. **归一化模式（E0–E5）对行业暴露几乎无影响**：同一规则下各臂 `mean|active|` 差异 **<0.01**，远小于规则/持仓数带来的差异。E0–E5 的风险差异不在行业维度。
2. 行业偏离主要由**持仓数**与**强买门槛**驱动：门槛 t=5% 后持仓集中在少数行业（s5 时 mean|active| vs 市场可达 0.041），组合方差因此放大。
3. 相对全市场的偏离普遍小于相对沪深300 → 沪深300 自身行业分布偏离市场，是主动暴露的主要来源。

## 4. 收益归因（决定性发现）

把全部 33 个目录 × 6 臂的持仓按建仓日行业汇总 `Σ(weight × ret_net)`：

| 指标 | 数值 |
|---|---|
| 全部配置总 P&L | **-11.77**（NAV 占比单位） |
| 其中 `801080 电子` | **+22.74** |
| 电子占总 P&L 比重 | **-193%**（即：**剔除电子后，所有配置整体亏损 34.5**） |
| 第二大贡献行业 `801050 有色` | +1.96 |

- **E0 exitnp_s5（此前"最稳 +25.6%"）**：总 P&L +0.200，其中电子 **+0.323**，即电子单行业已超过全部盈利；其余行业合计为负。电子仅 **4 笔**交易、累计权重 0.8、平均 +40.4%、胜率 100%。
- 其他配置同理：rolling_topn5 电子贡献 +0.14~+0.23，但组合总 P&L 仍为 -0.10~-0.33（电子之外全面亏损）。
- **P&L 集中度**（top3 |pnl| 行业占比，跨臂均值）：b500 0.05、exitnp 0.06–0.10、rolling 0.14–0.15、sbg exitnp t=5% 0.10 → 强买门槛越高、持仓越少，收益越集中于少数行业。

## 5. 结论

1. **"哪个归一化配置最好"的结论需重大修正**：E0（relative）在两个回测口径下的领先，主要来自**电子行业的少数几笔大额盈利**，而非稳定的选股 α。剔除电子后，E0–E5、b500/exitnp/rolling/强买门槛**所有配置整体为负**。
2. **出口规则是换手的主导变量**（exitnp 17.9×NAV vs b500 48.6×NAV，2.7 倍），对应成本差约 4.6pp/年；但 17pp 的超额差中成本仅占约 1/4，其余来自持仓路径/择时。
3. **强买门槛本质是"现金/风险预算"开关**：t=2% 完全无效，t=5% 把换手压到 12.9–25.3×NAV，但现金比升至 30–61%，且把行业暴露集中度抬高（放大方差）。
4. **归一化模式（E0–E5）不改变行业暴露**（臂间差 <0.01）→ 之前把 E0 优势归因于"无状态更稳健"的解释缺乏证据支持；真正的差异源在"持仓/择时路径 × 电子行情"的交互。
5. **样本极小且高度集中**：小组合（s5）+ 单区间 160 日 + 单 seed，结论的统计效力很弱（此前已知 t 值弱）。

## 6. 建议（后续可选，需另开 full 任务）

1. **行业中性化复测**：在回测/评估中加入行业中性与行业暴露上限（如单行业 ≤2×基准权重），检验剥离电子后是否仍有超额。
2. **多 seed + 多区间**：至少 5 seed × 2–3 个区间，报告 电子贡献占比 的分布，判定是"运气"还是"稳定偏好"。
3. **归因纳入正式产物**：将本脚本的换手/行业/P&L 归因固化为 `scripts/`（含单测）并接入 `run_eval_full.sh`，使每次回测自动产出归因表。
4. **换手口径补强**：当前 `nav` 曲线未落 CSV，日频换手以权重近似；建议引擎输出日频 NAV/现金序列。
