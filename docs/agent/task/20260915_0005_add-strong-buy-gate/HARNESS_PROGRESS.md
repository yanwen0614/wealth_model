## 结论（强买单变量）

1. **单调性成立**：`avg_cash_ratio` 与 `n_skipped_strong_buy` 随阈值 0.0→0.02→0.03→0.05 单调不减 ✅。
2. **2% 阈值几乎无作用**：s5/s10 跳过≈0（模型头部预测普遍已 >2%），仅 s50 少量（~110–480/臂）→ 头部预测尺度本身就 >2%。
3. **3% 中等、5% 强**：5% 时 s50 现金比 54–67%、s10 32–45%、s5 14–33%；交易笔数骤减（s50 b500 从 ~1900 降至 466–830）。
4. **无一致改善**：同阈值下各臂方向不一。改善例 E0 `exitnp s5 t0.05` +72.1%（基线 +22.5%）、E1 `b500 s50 t0.03` +15.6%（基线 +3.6%）；恶化例 E2 `exitnp s5 t0.05` -52.3%（基线 -6.3%）、E2 `b500 s5 t0.03` -51.7%（基线 -22.6%）。
5. **高阈值 = 高现金 = 从「选股」转向「择时空仓」**：5% 档样本量骤减（部分组合 closed trades <500）→ 方差极大，不能作为稳健 alpha 证据。
6. **相对最稳的是 s50**：`exitnp` 下 0.0–0.05 多数臂正超额；`b500` 下 E1 在 3% 最好（+18.7% 超额）。
7. **总体判定**：强买门槛是有效的「风险预算/空仓」开关，但**未见一致正超额**；收益差异主要由「进入现金的比例」驱动，需结合换手/行业暴露归因才能判定价值。
