## 固定抽样与原始行情

- 固定随机种子 `20251029`，从A预测NPZ的5135唯一代码抽6码：`603082.SH,301628.SZ,002573.SZ,301316.SZ,688659.SH,300246.SZ`。代码由单码文件 `Z:/dev/kline/day/{code}.parquet` 映射；6/6文件存在。
- 逐文件仅读2025-01-02至2025-12-22所需行及schema。6个文件schema一致：`code,kline_time,open,high,low,close,volume,amount`；无`is_trading`、ST、前收/参考价、直接`HIGH_LIMIT/LOW_LIMIT`或状态字段。抽样在2025-01-02、12-15/16主期末及12-17/18/19/22 buffer有OHLC行；这不代表全体或所有日覆盖。
- 抽样raw价格单位看似人民币元；例如603082.SH 2025-12-16 OHLC=35.03/35.19/34.58/34.65，原始volume=78,189,900、amount=2,720,777,418,000。adapter按volume÷100、amount÷100000转换为股/元，抽样量价VWAP量级吻合。尚未独立认证全体单位/数据质量。
- 该raw schema没有直接绝对涨跌停价；不能由ST比例、复权价或普通日线反推成“已验证”。日线OHLC也不能还原开盘排队/触板时序。

## 交易状态、上市、板别、公司行动

- `Z:/dev/quant_data_dev.db` 以SQLite `mode=ro` 读取schema和少量记录。`history_status`字段：`是否ST,是否除权除息,是否退市风险警示,是否停牌,涨停幅度,跌停幅度,记录类型,是否暂停上市`；**没有是否交易、绝对涨/跌停价、上市日、板别**。样例查询5码2025年只返回6行且停牌/暂停上市状态不能代表覆盖；已有索引为(code,date)。
- `stock_basic`提供listdate/listplate_name/is_listed/delistdate等；`code_list`提供entry_date/remove_date/source。抽样000001.SZ、300750.SZ、600000.SH、688001.SH可映射，920001.BJ为2026上市。字段是当前本地表记录，尚未证实历史PIT版本、2025年末退市/上市状态完整性或板别变更历史。
- `dividend`存在登记日、除权日、支付日、送转/送股/转增比例、实施公告日、红股上市日等字段。2025小样本正权益事件有603730.SH（每股送转0.30）、603050.SH（转增0.48）等；源表schema没有中登实际碎股分配证书、全字段可靠的公告时间戳/版本证据或税款最终清算证明。不能只取完成状态编码就认定权益金额/可交易日期全确定。
- `right_issue`有配股价/比例/进度/公告日。配股是否行权、资金占用与未行权权益处理均不能默认忽略或正常成交。公司行动样例不是事件总清单；本轮未扫描整年全表。
- 正送股/转增可改变可卖股数与10只持仓占用，未知舍入、上市日或税规则会影响账本。股息可按明确税前/压力税情景展示，但不能据此声称真实税后结果；权益事件缺口影响持仓数量或NAV时必须INCOMPLETE。

## 基准、日历、费用与core

- 沪深300 `Z:/dev/kline_index/day/000300.SH.parquet` schema为code/time/OHLC/volume/amount，3338行。SQLite SSE交易日历2025有243日，与预案已核指数243日口径一致。抽样指数close：2025-01-02 3820.3952，2025-12-16 4497.5545；需全量核对243日与端点，不允许缺日沿用前值。12-16之后buffer交易日为12-17、18、19；预测不含12-17至31不代表无需执行buffer。
- `resolve_historical_costs`对2025应给卖出印花税万5、过户费双边万0.1（2022-04-29后）；佣金万2/min5由`CostConfig`显式固定。现装core默认`SlippageV1`为σ-ADV变量滑点：impact=1、ADV/sigma窗口20、sigma clip 0.5%–8%、p_cap=10%、spread_floor=2bp、slip_max=5%、missing volume=warn；滑点随价格、波动、成交额/历史长度变化，**不满足预案“固定滑点”**。若预注册要求固定百分比，必须在运行前选定比例并确认core可用配置能表达；否则列为实现阻断，不能事后把默认σ-ADV称作固定滑点。还需审查缺量warn时的spread-only成交降级是否可接受。
