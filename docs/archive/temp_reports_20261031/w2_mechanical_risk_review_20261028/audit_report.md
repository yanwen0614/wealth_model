## Episode 归因与完整性

episode_summary/fills 虽提供 episode_id 与成交关联，但未提供完整且无歧义的公司行动权益分配、真实税费和最终证券成本归属；E日仍有持仓（B1 603185.SH 1,200股、688390.SH 400股；C70 603185.SH 800股、688390.SH 300股；S1/S2各有603185.SH 400股），随后 buffer 清仓。故无法无歧义重构 top 盈利/亏损 episode 贡献；本审计不计算个股盈利、episode 盈亏或 label。

四个 daily_account 均129行（anchor+125主期+3 buffer），日期唯一；NAV=现金+持仓市值+应收核对误差≤0.01元；W2 各目录 artifacts.json 所列 sidecar 均逐文件 SHA256 与声明匹配。summary 文件哈希、预注册冻结沪深300 CSV、第二次审计、exposure README 哈希列于 `source_hashes.json`。

W2 四策略状态均为 INCOMPLETE / BLOCKED。20%现金股息扣缴是 `cash_dividend_20pct_stress` 压力情景，不是真实个人税；公司行动 README 仅证实模拟中三笔分红触达，相关事件税务仍未知。coverage 摘要有 15,620 缺bar、16,605 unknown，来源 `source_known=false`；逐条明细只覆盖摘要的一部分，不能将差额归因。执行来源 known-at/PIT 未知，公司行动全暴露及实施资格未证。真实目标资格仍未证明。

风险结论只描述这一个冻结窗口的账本路径。不得用已查看的同窗结果事后筛选固定策略或参数，不做显著性、泛化性或生产就绪声明。第二次审计曾指出旧独立审计把 W1/300502 登记持仓统一写4,000股的错误；该错误与本次 W2 数值无关，本报告不据此沿用 W1 结论。
