# 独立审查清单

复核对象必须是单一编码owner交付的冻结worktree提交和SHA，不读写其他活跃树；逐项引用文件/事件证据。

## 方案与冻结边界

- [ ] 新worktree从指定冻结HEAD创建；只有一个编码owner；CA/W1原树与证据、输入NPZ、checkpoint、安装wheel均未修改。
- [ ] 实现只新增NPZ→现有ranking契约桥及薄调度入口；账户、撮合、费用/CA应用仍只有一个backtest-core账本。
- [ ] A/B不按已有指标或本轮表现择优；唯一固定政策和配置除来源身份外一致；5槽政策明确是5只候选且≤10，不暗称top10。
- [ ] HORIZON=10配置与exp_ret中心期望公式核对；provenance不声称H5；历史验证期性质正确披露。

## 信号来源与完整排名

- [ ] NPZ必需键/类型/长度、code/date合法、重复键0、非有限值拒绝、排序稳定规则明确。
- [ ] A/B日期、代码、true_ret全量逐键一致；原始NPZ SHA与独立来源manifest/report SHA均验真且写入输出。
- [ ] 若用旧signal parquet，逐键逐值与NPZ等价，并存储parquet SHA及上游NPZ SHA；不能拿parquet单SHA代替上游来源。
- [ ] 未知状态候选保留在原rank和机会审计中；只对对应交易机会保守拒单；绝不删候选后重排或静默漏码。

## 真实账户约束

- [ ] core运行器及实际安装wheel身份/hash固定；ExecutionUpdate observer无丢事件、重放冲突失败；无第二账本。
- [ ] 初始资金均1,000,000；实际持仓证券数在每次成交/状态转换后、每日收盘都≤10；待成交买单、locked、CA entitlement容量均计入核容。
- [ ] T+1、历史板别数量规则、停牌、涨跌停、ST、未成交/部分成交、限价未知、费用、滑点按实际执行日处理；未知绝不默认为可成交。
- [ ] 原始未复权行情覆盖锚点至E后3个交易日；行情单位、缺bar与停牌区分、价格和状态冲突均有拒绝测试。
- [ ] 历史公司行动覆盖完整；现金、股份权益、碎股、未知税务状态可追溯；不把压力税情景冒充实际个税。
- [ ] 历史费用resolve到每笔成交日与代码，费率来源及滑点算法冻结，A/B一致；不使用单一当前费率替代历史表。

## 窗口、基准、产物和门禁

- [ ] 锚点2025-01-02；E=2025-12-16；完整日历与E后恰好3个交易日buffer；E日后不再发新买单。
- [ ] 主期只计至E日收盘NAV；buffer清算独立报告；任何执行/估值缺口均INCOMPLETE，不缩短窗口。
- [ ] 沪深300价格指数close-to-close同锚点/终点，每日close齐全；缺日失败，不前值填充；明确不含分红再投资。
- [ ] 输出逐日现金/应收/持仓股数及市值/NAV、成交与费用、拒单/locked/状态来源/未知机会、CA、指数、来源哈希及覆盖报告。
- [ ] 逐日NAV恒等式与core账户快照一致；终端审计覆盖逐订单上限和未解决订单；未因全拒导致零暴露而给目标PASS。
- [ ] 单测先红后绿；定向用core fixture覆盖NPZ、硬上限、停牌/涨停/未知、T+1、CA、历史费率、buffer、基准缺日；ruff与adapter/CA审计套件通过。
- [ ] 独立QA只读冻结版本，报告PASS/FAIL与证据；FAIL由owner最多修两轮；全量A/B运行只能在门禁PASS后启动且用tmux。
- [ ] 目标判定三条件同时成立：完整审计、扣除已声明适用成本后NAV≥本金且严格跑赢同期指数、实际持仓始终≤10；否则明确FAILED或INCOMPLETE，不得事后改政策。
