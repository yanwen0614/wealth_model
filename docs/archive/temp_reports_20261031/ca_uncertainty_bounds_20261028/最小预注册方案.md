# 最小可审查方案（未来设计，本轮未运行）

目标：先用尽量小的单事件机械验证识别分歧，再决定是否值得做全窗探索。不得用W1/W2选优修改策略，也不得把已烧掉的历史窗口当干净考试。

1. 先形成证据卡：取2021-030官方原PDF、适用深圳分配规则历史版本、精确比例/总额/账户单位/现金替代/上市可售时点，保存URL、字节hash、页码与摘录。未取到时明确`official_fractional_rule_verified=false`，不得用常见规则填空。
2. 冻结四策略各自6月7日末完整账户、登记权益、活动订单、registry、episode与未用预算状态；只有账户现金和股数不够。冻结源码/已安装wheel、配置、信号、单股raw和state哈希；验证恢复后的前缀账逐事件一致。若无法恢复隐含策略状态，应先验收恢复方案，不能伪称从断点继续。
3. 建立假设矩阵：若只研究送转所得二元性，每策略固定新增floor/ceil两值；现金税身份、精度、可售时点、委托调整、未知状态各列明固定值及依据。多个未知不得隐式包进“只有两分支”。纯敏感性实验不向生产源库写覆盖。
4. 先只检查6月8日CA、旧订单执行和当日收盘状态：原46.18卖单不可成交；原15.95/3.08买单不可成交；其他卖单按获验引擎规则独立核算。核股份权益/现金/成本守恒、卖出余额规则、未上市权益占槽和策略调用时点；此阶段也须独立QA后才执行。
5. 若再开展动态探索，事前固定四策略×两分支共8个延续实验（不是重选原八窗），所有交易必须各自依状态重新生成。报告首个不同决策日、订单/股数/价格/现金/slot分歧、拒单及碎股清理；固定失败分支保留，不仅报告成功者。
6. 设完整状态S、确定转移F、外生行情X。单一二元初值条件下S⁻ₜ₊₁=F(S⁻ₜ,Xₜ)，S⁺ₜ₊₁=F(S⁺ₜ,Xₜ)，两终值的min/max才构成该有限假设集内的精确包络；不得假设ceil终值更高。各策略是不同反事实实验，若研究四个真实账户同时分配，需另验全局总量约束，不能独立拼接四个ceil。
7. 若存在部分成交/随机/税身份等额外分支，需枚举所有被认证可能性，或用保守可达集合Sₜ₊₁={F(s,u,Xₜ):s∈Sₜ,u∈Uₜ}。不得只运行“看似极端”的全floor/全ceil并称其覆盖混合路径。现金/slot/episode等保留离散关联；逐列取min/max再随意组合可能创造不可达状态，也可能漏掉阈值决策。
8. 预先固定主期E=6月30日、buffer=7月5日、同日沪深300与费用口径；分别报告E日估值和buffer清仓情况。若任一分支中断/遗漏，区间不得标完整。

独立QA最小清单：

- 来源卡是否证实2021适用规则，而非其他年份/市场先例；假设集合是否真正穷尽。
- 恢复前缀hash及账户/订单/内部策略状态一致；同一冻结版本、只读核查、无并发写源。
- 新增股非整数的保护没有被绕过；清仓能正确处理1/2、20/21等卖出余额；最小佣金/容量/可售时点和slot释放可追踪。
- 会计逐日核`cash+股票市值+净应收+未上市权益=NAV`，避免重复计入新股、股利、扣税或交易费用。
- 逐策略核对首个分歧与全部终态；两分支排序不作单调假设；不得以后验收益改规则。

W2另设只读税务工作表：按事件id/登记批次一行，列毛额、已计预扣、条件税率/税额、持有期、税务身份、实际扣缴时点与来源。当前三笔批次核对已完成；如未来只做固定路径会计重估，使用M+W−T即可，不需要重跑策略。若研究税时点对决策影响，必须单独事前设计并经QA批准，不得用该重估表冒充动态实验。

最低交付优先级：先公告/历史规则证据卡与6月8日状态转移审查，避免为了看期末数字先启动全窗。真实账户如可提供中登/券商持有变更直接核结果；模拟账户无法直接查询分配结果时，保留两分支探索标签。

在官方碎股规则、数据时点和税务身份未获验前，即使所有探索分支数值非负、跑赢指数且持仓≤10，也只可称“预设情景内数值稳健”，**不可宣称实际税后目标达标或生产验收通过**。W1/W2均属已见历史数据，干净考试仍须按既定规则使用2026年9月后新数据。
