# 方法与字段说明

1. 逐行流式读取四个策略的订单成交JSONL，选择三个证券的所有 `status=filled` 记录，登记前后买卖均纳入。
2. 登记日前成交买入数作为路径重建的登记股数；毛息=股数×输入材料列示的每股税前股息。登记日后卖出按成交日志顺序FIFO分配给登记持仓，超额卖出不冲减新买入；登记后新增买入保留在全量成交列表。
3. 条件税额=毛息×20%，仅为假设全部批次≤1个月等前提下的条件值。daily_account只观察累计gross/stress字段，不把累计量当单笔扣款。
4. 税法持有期取决于转让交割日前一日。订单流水只有交易日期，所以机器账证明确标注持有期税档与真实税额未验证，不将交易日差冒充严格核定。
5. 税务机关页面原文核对税率、扣缴时序和FIFO定义；本地两份公告按字节计算SHA-256，并用已安装的PyPDF2只读解析页数及页面文本：酒鬼酒2页、凯莱英3页，关键税则/登记日页码见独立审计报告。广州发展原公告缺失。

12份JSON：`<策略>_<代码>.json`。字段含原JSONL源行号、fill_id、买卖方向/日期/股数、FIFO分配、登记剩余股数、条件毛息税额及未验证状态。
