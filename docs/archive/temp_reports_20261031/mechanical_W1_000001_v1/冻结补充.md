# 冻结补充：核心引擎边界

- 固定执行配置 `final_liquidation="skip"`。主期/缓冲末仍有仓位时保留真实残仓，不允许引擎另造强平订单；残仓使既定最终现金断言失败并如实记录。
- 已安装 core `MarketBar` 只接收 limit_up/limit_down 布尔值，不接收绝对价。因此由临时回放器在构造 provider 状态前，用逐日 HDF 绝对上下限和 raw open 做确定性门控；若 open 位于任一法定边缘，两方向均设置阻断标志。原始绝对价和边缘判定另存，不篡改 HDF 输入。
- 仅对缺少/异常 HDF 行、非法旗标、缺绝对限价、缺 raw open、停牌或限价边缘拒单；ST/SUSP 原始值均保留，ST 的 core 状态已知标记只表示字段完整，不推断额外交易资格。
- run_account_backtest_from_orders 逐日运行至 2021-07-05；`evaluation_end=2021-06-30`、anchor 为首日 2020-12-31，buffer 日期仅用于账户维护。Scripted 策略在冻结的两个信号日之外恒返回空订单。
- 每个实际成交后的 `execution_price` 必须落在同日 HDF 绝对低/高限价内，否则整次回放标为 FAIL；失败输出仍保留原始 TradeEvent/OrderResult，不做事后删单或换价。
