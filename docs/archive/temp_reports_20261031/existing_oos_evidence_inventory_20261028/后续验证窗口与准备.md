# 未用窗口与验证准备建议

## 资格先后

1. 真正干净考试只认2026-09之后；现有审计只确认部分行情/指数业务日期到2026-09-30，未确认盘前版本、全市场覆盖、冻结信号或连续执行记录。因此截至2026-10-28无可宣称合格的干净窗口。
2. 2021及更早/2022~2025未见窗口可以做历史稳健性与工程补证，但都是策略开发者已接触过的历史，必须标为“补充历史验证”，不能升格为独立确认。先固定一个策略版本及全流程，全部报告结果，不再从候选/月份中择胜者。
3. 最值得先补的历史切片：树模型expanding报告中2022-01至2025-06的连续滚动折，逐折复用既有冻结规则和账户上限≤10重建审计；这是已有时间切分而非新数据准备，预估1~2工作日只读输入盘点+2~5工作日账本计算/复核（若没有逐日预测/交易侧车则不可行，需另行授权计算）。不能用改成≤10后出现的结果声称原策略已经通过。
4. 次选2025-07~12：仅能作为已污染开发段复核（λ消融、多策略扫描都看过），记录胜/败但不选winner；优点是已有CNN信号/回测缓存可能可复用，预计半天到2日对齐指数、费用和逐日持仓，确认账本存在前先检查文件清单，不重跑训练源。

## 建议固定协议

- 当前没有历史候选可称“最有资格”。若做工程性历史复核，固定整组W1/W2 B1/S1/S2/C70规则，四策略全报；W1保留失败，W2不得根据+23.68%挑B1为胜者。复算不改变预注册，也不补造2021即时冻结证据。
- 面向收益目标的候选只有在用户确认候选定义之前冻结才可进入干净前瞻；选择可参考既有理论/规则，但不得比较任何新算出的目标窗收益后选模型。至少保留一个后续连续新时间段作终局确认，不在其间调参。
- 既有W2的HS300是价格指数、不含分红再投；建议在新考试开始前固定采用沪深300价格指数或全收益指数之一，并保证投资组合和基准使用相同锚点、终点及现金等待区间。已有报告不可事后切换基准。
- 初次干净验证窗口从首个“数据源时点已证、全市场输入完整、冻结后连续产生信号”的交易日起算；若现有数据只到2026-09-30，窗口长度仅21个指数交易日，统计效力弱，且不足以独立证明跨市况稳定。等待新日期积累是必须条件，不用2026-01~08补长窗口。

## 需要停止的情况

- 若因子/状态/公司行动首次可得时间不可证、全市场行情缺失，或执行账本身份不能闭环：当窗标NO-GO/INCOMPLETE，不报告策略达标收益。
- 若模拟假设能成交但没有实际订单/成交日志，结果只能叫“固定规则的历史/前瞻模拟”，不能称真实可实现收益；目标中的成本必须包含所有明确交易成本，税务未知须单独给界限且不能以压力税率充当真实税后值。
- 不读取训练大源的做法：只使用已封存checkpoint、已产生信号缓存、每日/窗口输入增量及parquet footer/选择列；如不得不访问全量文件，限定列投影与行过滤并先核对文件身份，禁止完整重读4GB源。
