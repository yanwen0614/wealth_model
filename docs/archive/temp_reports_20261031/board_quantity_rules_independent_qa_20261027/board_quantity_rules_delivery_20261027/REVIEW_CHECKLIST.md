# 七关审查清单

| 关卡 | 审查要点 | 结果 |
|---|---|---|
| 范围 | 按历史交易日期与板别规则区分限价数量，超单笔上限拒绝 | PASS |
| 复用 | Strategy 经可选 resolver 调用统一 QuantityRule，拒绝时不生成 OrderIntent | PASS |
| 契约 | 科创限价 min=200、step=1、max=100000；主板历史规则可配置 min=100、step=100、max=1000000 | PASS |
| 财务状态 | 100股买入拒绝后无订单ID/请求股数，预算承诺账不被伪造为成交或挂单 | PASS |
| 错误拒绝 | 日期、来源、side、数量类型、规则匹配未知/歧义均拒绝；上限先于全余额例外 | PASS |
| 可验证性 | RED确实发出100股；GREEN 100拒绝、200/300允许；目标及完整 backtest 测试通过 | PASS |
| 兼容 | `quantity_rule_resolver=None` 保持旧路径行为 | PASS |

## 关键语义核对

- SSE 2019 科创板官方通知第二十条：限价申报不少于200股、不超过10万股；规则没有200股整数倍要求，step=1符合规则语义；余额不足200股全额申报卖出。
- SSE 2020主板3.4.7、3.4.9、3.4.11：买入100股整数倍；卖出不足100股余额一次申报；单笔上限100万股；A股最小价位0.01元。暂缓条款未暂缓上述三条。
- 卖出全额可含零股，但数量先受单笔最大值限制；部分卖出须符合最低量/步长。该门校验的是委托数量，不限制成交回报的部分成交数量。
- 此实现本身不提供生产规则表；接入方必须提供来源明确、日期覆盖明确的 resolver。resolver 缺失时为兼容而跳过规则门。
