## 已核事实

- 两个 NPZ 均只有 `exp_ret, true_ret, dates, codes`，各1,180,872行，float64 / datetime64[us] / U9；日期2025-01-02至2025-12-16，共232日、5,135码。A/B 的 dates、codes、true_ret逐元素相同；(date,code)重复为0，四数组非有限值均为0。
- 每日截面 5,041–5,128 行。预测日均在指数2025日历中；指数共243日，少于指数的11日全部是2025-12-17至12-31，属于预测自然期末，不是随机缺交易日。另有三处春节、劳动节、国庆长休市间隔。
- 两个评估JSON各报告 `n=1,180,872`；其checkpoint路径在本地均存在。对应运行配置称 TRAIN_END=2024-12-31、VAL=2025全年、SEQ=60、relative、F=53、`HORIZON=10`。信号含义是分类概率乘52类中心的期望收益排序（见 `predictions.py` 锁定公式）；运行器当前 provenance 却固定 `PREDICTED_HORIZON=5`。回放只消费排序分数，但必须修正/隔离该谱系声明，禁止沿用错误的5日标签声明。
- 本区实际存在2025 parquet，footer为11,413,377行/11 row groups、覆盖至2025-12-31；其 OHLC 为后复权，导出元数据显示行情/因子最大日期晚至2026-08。不能把它直接当历史真实成交价或PIT特征证明。`Z:/dev/kline/day` 存在；沪深300 `Z:/dev/kline_index/day/000300.SH.parquet` 有3,338行，覆盖2013-01-04至2026-09-30，2025全年有243个指数日线交易日。
- 报告 `eval_fullA_2025.json` / `eval_fullB_2025.json` 记载的回归分数不等同组合收益。既有回测汇总明确A/B的2025账户回测为null；既有2026数值已烧样本，不纳入本计划任何成绩比较。

## 最小固定研究协议（所有候选一次性并列）

1. 两账户各自初始资金 ¥1,000,000；模型A与B完整并列；每日收盘形成次日开盘订单，A股T+1卖出规则；固定目标持仓数10，rank>10即发全量卖单，缺信号不得伪造排名。没有信号/候选不足时持现金。
2. 锚点统一为2025首个交易日2025-01-02；结束日采用双方共同最后信号日2025-12-16，主期账户NAV按该日收盘标记，随后固定3个交易日只清算并单列buffer，不把buffer收益混入主期。若实际订单/清算需要的开盘、收盘或日历数据缺失则整组标INCOMPLETE，不缩短/延长日期。
3. 以相同锚点/终点的沪深300**价格指数 close-to-close**为主比较，明确不含指数分红再投资。策略必须同时满足主期净NAV≥本金、严格大于基准、每日及每次订单结算后正持仓证券数≤10；报告差值百分点、金额与完整账本。结果只能是探索性模拟结论。
4. 暂定显式成本：买卖佣金各万2、单笔最低¥5、卖出印花税按2025规则万5、沪深过户费双边万1；滑点须固定、事前写明参数并按同规则A/B执行。CLI的费用五参可表达这些值，但需确认core滑点默认的数值及历史适用性后冻结；不得运行后调费率。公司行动分红/送转需原始事件与登记权益入账；实际税额未知时分报税前与固定压力政策，不声称真实税后。
5. 硬上限必须由执行策略层预留退出/替换槽位，并在每笔买单前按“现有持仓 + 买入成功最坏情形 - 已确认卖出”核容；跌停/停牌/未知卖出导致容量占满时禁止新买，拒单/锁单持续记录。单纯 `target_size=10` 或收盘快照峰值不足以证明日内/订单级硬约束。账本须逐日给现金、应收、持仓代码/股数/市值、NAV、峰值；同时列出成交、拒单、锁单、部分成交、费用和行情/状态来源。

## 交易数据与约束审查

- 当前 CLI 默认读训练 parquet 的后复权OHLC；ST名单默认为空，市场层按该名单决定主板ST涨跌停。故普通CLI路径会把ST规则当非ST规则处理。应改用已有 `CnnRawMarketDataProvider` 原始行情输入及已验证状态；缺行与停牌在adapter中有区别，但未知状态、未知限价不能默认为可成交。
- `CnnMarketDataProvider` 对无法计算涨跌停只增加 `limit_unknown_count` 并用False占位；日线OHLC无法判定集合竞价排队/触板顺序。必须把未知限价机会列为拒绝或全窗阻断，并在结果给出计数/代码日明细。
- Adapter已有core订单撮合、开盘执行、T+1、佣金/印花/过户与σ-ADV滑点；`target_size`映射PortfolioConfig.top_n，然而CLI不导出逐日snapshot/trade事件，不注入CA、verified states或逐日历史费率resolver，也不运行 `audit_execution`。`write_cnn_result`可输出manifest/metrics/trades，但还需导出并校验账户snapshot、拒单/locked和行情计数。
- 现有benchmark函数按策略交易日对齐指数收盘；无该日指数收盘时沿用上次值（收益记0）。本计划要求先校验2025共同日历完整243日并固定2025-01-02锚点、2025-12-16终点，缺指数日不得静默沿用。
- 现有公司行动Provider/ raw execution接口可接线，但常规CLI没有参数入口；主区已安装core wheel身份应在隔离实现时记录版本/哈希并确认能力。不能从普通训练parquet footer推断已具备逐笔公司行动、ST、停牌、上市退市PIT或历史涨跌停证据。

## 是否可直接执行与工期

- 可直接执行的只有**受限的2025目标10探索**：主区CLI两次调用，NPZ格式兼容，A/B成本参数一致，指数文件可读。它缺逐日账本、原始成交行情/PIT状态/CA与严格硬上限审计，输出不能作为目标证据；不建议把两次汇总数值当交付结论。
